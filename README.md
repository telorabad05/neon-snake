# Neon Snake 🐍

Game ular klasik dengan tampilan neon yang modern — langsung bisa dimainkan di browser HP maupun komputer, tanpa instal apa pun.

## Cara Main

- Tekan tombol **MULAI** (atau tombol apa saja) untuk memulai.
- Makan makanan merah muda yang berdenyut untuk menambah skor (+10) dan memanjangkan ular.
- Makin panjang ular, makin cepat gerakannya!
- Permainan selesai kalau ular menabrak dinding atau badannya sendiri.
- Skor terbaikmu tersimpan otomatis di perangkat.

## Kontrol

| Perangkat | Kontrol |
|---|---|
| Keyboard | Tombol panah atau **W A S D** |
| Layar sentuh | Geser (swipe) di area permainan, atau tombol arah di bawah layar |
| Jeda | Tombol **Jeda**, tombol **P**, **Esc**, atau spasi |
| Main lagi | Tombol **Main Lagi** di layar selesai |
